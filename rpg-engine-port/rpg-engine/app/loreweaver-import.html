Import from Loreweaver

Personas → hero library

Import your Loreweaver personas as saved heroes. A linked snapshot is created in the game's hero library — open the game, forge a hero, and Load it from the library in any world. Mapping: name → Name, description → Persona, avatar → Portrait; the other bio fields stay blank for you to fill in the game (stats are always per-world and never imported).

The import keeps a link to the source persona. Come back here to check for changes — updating overwrites only the imported fields (Name, Persona, Portrait), never anything you added in the game.

Character cards → world NPCs

Add a Loreweaver character as a standing NPC in one of the game's worlds. Mapping: name → Name, description + personality → Persona, scenario → Extra details, card image → avatar. Fill the rest (race, appearance…) in the game's World Editor. New adventures see the NPC at once; a RUNNING adventure picks it up on its next load.

World Info → world lorebook

Copy a Loreweaver World Info book into the selected world's lorebook. Keywords (secondary keys merged in) → triggers, constant entries → always-on, comment → title. ST macros like {{user}}/{{char}} stay literal — edit them in the World Editor if needed.
