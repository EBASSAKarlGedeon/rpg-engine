Import from Loreweaver

Import your Loreweaver personas as saved heroes. A linked snapshot is created in the game's hero library — open the game, start/forging a hero, and Load it from the library in any world. Mapping: name → Name, description → Persona, avatar → Portrait; the other bio fields stay blank for you to fill in the game (stats are always per-world and never imported).

The import keeps a link to the source persona. Come back here to check for changes — updating overwrites only the imported fields (Name, Persona, Portrait), never anything you added in the game.
