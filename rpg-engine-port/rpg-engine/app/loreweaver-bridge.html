Loreweaver bridge

Route the game's AI calls through the Loreweaver server, using one of your Connection Manager profiles — the same connections the chat uses. The API key is resolved server-side from the profile's stored key and never enters this page. Streaming works.

How it works

  1. The chosen profile decides everything: endpoint URL, model, and API key (its secret-id entry in Loreweaver's server-side key store).
  2. The game's Settings > AI Model base URL and model are ignored while the bridge is on (its key field can stay anything). Per-call routing (trackers etc. on a cheap second profile) is planned — right now one profile serves all calls.
  3. The cheap secondary model (the Perchance AI slot on cheap-model.html) also routes through the same profile while the bridge is on.

Only works when this page is served by Loreweaver (same origin). Keep the bridge off for standalone use (python http.server).
