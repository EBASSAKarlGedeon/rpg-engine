Loreweaver bridge

Route the game's AI calls through the Loreweaver server instead of calling model providers from this page. The API key is resolved server-side from Loreweaver's own key store (Settings > API Keys > Custom) and never enters this page. Streaming works.

Status: bridge is …

Which Loreweaver connection should serve the game. For Custom, the key must be saved in Loreweaver (Settings > API Keys > Custom). Other sources use their own key stored in Loreweaver.

Setup

  1. In Loreweaver, connect the provider you want the game to use (its key is then stored server-side in Loreweaver's secrets).
  2. In the game: Settings > AI Model — pick OpenAI (custom-compatible), enter the same Base URL as in Loreweaver and the model name. The API key field can be anything non-empty ("loreweaver") — the bridge replaces it with the server-side key.
  3. Turn the bridge on here and run Test call.

The cheap secondary model (the Perchance AI slot on cheap-model.html) also routes through the bridge while it is on — its Base URL + model are applied the same way. When served standalone (python http.server), keep the bridge off.
