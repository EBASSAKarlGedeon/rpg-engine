# RPG Engine

RPG Engine for Loreweaver (SillyTavern fork). Currently at the minimal test stage.

## Installation

1. Open Loreweaver
2. Extensions → Install extension
3. Paste `https://github.com/EBASSAKarlGedeon/rpg-engine.git`
4. Refresh page

## Testing (Stage 1-4)

Look for "RPG Engine" in Extensions settings (right panel).

- Drawer appears ✅
- Checkbox state persists across refresh ✅
- Test button shows a toast ✅
